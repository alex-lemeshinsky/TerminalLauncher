# App icon

Generated with the built-in imagegen tool on 2026-10-06. The macOS icon sizes
live in `App/Assets.xcassets/AppIcon.appiconset`; `project.yml` selects `AppIcon`
for the host app. The largest PNG is the 1024-pixel master used by the app.
Smaller PNGs were resized with macOS `sips`, preserving transparency.

## Generation prompt

```text
Use case: logo-brand
Asset type: production macOS application icon for TerminalLauncher, a desktop widget for saved folders that launch Terminal.
Primary request: create a polished, distinctive macOS app icon combining a folder with a terminal command prompt.
Subject: one substantial cool blue folder with a dark inset terminal face and a crisp luminous white >_ prompt. The folder tab clearly establishes the folder silhouette. Simple bold geometric shapes that read at 16 pixels.
Style/medium: refined native macOS icon, gently sculpted 3D depth, restrained soft highlights and shadows, premium utility aesthetic.
Composition/framing: square 1024x1024 canvas, centered rounded-square dark graphite tile occupying about 88 percent of canvas; folder symbol centered and large, safe margins, front view. Transparent outside the rounded-square tile; retain smooth alpha edges.
Constraints: a single finished icon, no mockup, no border frame, no small decoration, no lettering or app name, no watermarks. Only visible glyph is >_.
```
